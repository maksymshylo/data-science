# Data Science Labs

Labs from the Institute of Physics and Technology, KPI.

A collection of machine learning and deep learning implementations 
covering fundamental algorithms and neural network architectures.


## 📚 Labs Overview

### Lab 1: Basic Machine Learning
**Linear Regression** 
- Custom gradient descent implementation
- Synthetic data generation
- Comparison with sklearn

**Logistic Regression**
- Binary classification
- Custom implementation with gradient descent

**Decision Tree**
- Tree-based classification
- Visualization of decision boundaries

### Lab 2: Scikit-learn Classifiers
- Multiple classifier comparison
- Model evaluation and metrics
- Hyperparameter tuning with GridSearchCV

### Lab 3: Unsupervised Learning
**Topics covered:**
- **Dimensionality Reduction**: PCA, t-SNE
- **Clustering**: K-Means, silhouette analysis
- **Gaussian Mixture Models**: EM algorithm
- **Text Processing**: TF-IDF, word clouds, text classification

### Lab 4: Deep Learning with PyTorch
- **CNN Image Classification**
- **Multi-layer Perceptron**
- **RNN Text Classification**

## 🚀 Setup

### Prerequisites

- Python 3.12+
- virtualenv

### Installation

```bash
# Install system dependencies (for decision tree visualization)
sudo apt-get install graphviz

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```
